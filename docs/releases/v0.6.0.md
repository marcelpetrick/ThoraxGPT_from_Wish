# ThoraxBench Local 0.6.0 — Thorax review with plain-language verdicts

ThoraxBench Local is a local workbench for reproducible thoracic CT research. This release
focuses on thorax review: real hospital DICOM folders open reliably, every report leads with
a plain-language verdict, and models are labelled by how well they are known to work.

### New in 0.6.0 (since 0.5.4)

- **Real-folder import fix.** Vendor private header values that pydicom mistypes (for example
  a 6-byte ELSCINT1 `(01F1,1026)` Pitch) are kept as raw bytes instead of rejecting whole
  slices; public tags stay strict. `scripts/dcom_evaluator.py` checks a folder locally and
  prints only aggregate JSON (see `docs/wiki/Checking-a-real-DICOM-folder.md`).
- **Verdict first.** HTML/Markdown reports and the app open with at most three plain
  sentences: what was flagged and where (slice, side, size), what was checked, what to show a
  radiologist. Reports switch between English and German. One short disclaimer line replaces
  the repeated paragraphs (full text in `docs/DISCLAIMER.md`). An optional local LLM may
  rephrase the verdict from the structured facts only; any new number, finding, cause or
  diagnostic word falls back to the fixed wording.
- **No identifiers in shareable reports.** SeriesInstanceUID and patient identifiers are
  removed from readable reports and their embedded JSON (the JSON download keeps them).
- **Model fit markers.** The selector groups models as 1️⃣ recommended (MONAI nodule
  detector), 2️⃣ thorax-specific but limited (HU density baseline, uninstalled 3D CT models)
  and 3️⃣ research controls, each with a reason. Test runs on a synthetic phantom and two
  calibration cases are in `docs/model-test-runs-2026-10-20.md`.
- **Full thorax review.** One job checks the whole chest: the detector and density rules on
  the whole volume, optionally an image model over every 5 mm slab in coarse-to-fine order,
  with measured time per image, remaining time, stop-and-keep-partial, and a ranked "look
  here" list. Density-only entries are weak cues and never decide the verdict.
- **Parser fix (important).** `present: false, confidence: 0.0` was read as "100 % present",
  turning model negatives into discarded positives. The yes/no answer now sets the
  direction; confidence only the strength. With the fix, MedGemma answers "absent" for
  every label, including known nodules, so it stays a research control.
- UI/UX red-team fixes: stale study after a failed folder open, explained disabled Run,
  quieter progress, translated folder errors, warnings worded as warnings.
- Branch review and `/code-review` findings fixed: honest stop reporting, consistent sides
  in app and report, one GPU job at a time including the optional LLM wording.

### Available research workflow

The workbench includes optional MONAI lung-nodule candidate review, sequential local-model
jobs, self-contained HTML reports with image evidence, English/German UI and light/dark
modes. Model weights require explicit setup; opening a folder does not start inference.
The repository's approved 30-second demo videos are in `media/`, with attribution and
selected-case/training-overlap limitations.

### Start from the repository root

```bash
uv sync --frozen --all-groups
uv run thoraxbench serve
```

Open http://127.0.0.1:8000. Optional detector setup is documented in
`docs/detector-baseline.md`; no weights are downloaded automatically.

### Scope and limitations

Research use only. This self-made experimental tool may produce incorrect, incomplete or
misleading findings. It is not professional medical advice, a diagnosis or a medical device.
Do not use outputs for diagnosis or treatment decisions.

MONAI proposals are uncalibrated; its LUNA16 training overlaps LIDC. With the parser fix, MedGemma
answered "absent" for every label in test runs, including known nodules; it is a research
control (3️⃣), not a reader. Passing software tests does not
establish model accuracy. The patient-level 20% sealed holdout remains excluded from
development and this release validation. Local registrations, the queue and downloadable job diagnostics remain session-only.
Sanitized job event logs persist across server restarts with bounded local rotation.

See `docs/model-test-runs-2026-10-20.md`, `docs/full-review.md` and
`docs/review-ui-redteam-2026-10-19.md` for evidence and review fixes, and `docs/manual.pdf` in the repository or the attached `manual.pdf` for the
operator procedure. Checksums accompany the wheel, source archive, manual and diagnostic helper.
The helper requires the installed project environment; from a checkout use
`uv run --no-sync python scripts/dcom_evaluator.py --help`.

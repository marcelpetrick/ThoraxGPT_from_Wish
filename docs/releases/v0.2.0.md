# ThoraxBench Local 0.2.0

Historical record for the named review/release. Preserve its scope and measurements.
For current behavior, use [the plan](../plan.md) and [the operator manual](../../manual.html).

This release adds live runtime feedback, exploratory model comparison and guided local
model setup to the research workbench.

Research use only. This is a self-made experimental tool created with AI assistance. It is
not medical advice from a qualified healthcare professional, a diagnosis or a medical device.
Findings may be incorrect, incomplete or misleading. Do not use them for diagnosis or
treatment decisions. Educational severity does not establish whether care is needed.

## Start the workbench

Use the source archive or clone the repository. Open a terminal in the checkout root.

1. Run `uv sync --frozen --all-groups`.
2. Run `uv run thoraxbench serve`.
3. Open `http://127.0.0.1:8000`.
4. Select **Create synthetic demo**.
5. Run **heuristic-hu**.
6. Download the HTML review.

Expect synthetic nodule and fluid findings. This verifies the software path, not accuracy.
Read `manual.html` or `manual.pdf` for configuration and recovery instructions. Restart an
already running server after upgrading, then reload the page.

## What changed

- Live browser elapsed time is separate from recorded engine-stage duration.
- Runtime forecasts are rough planning ranges. Browser-local measured history refines
  them. They are not deadlines or evidence of inference progress.
- The comparison switch runs available recommended models sequentially. Failures,
  abstentions, skipped models and partial results remain explicit.
- An offline comparison HTML combines findings, per-run status and embedded evidence
  reports. Repeated findings remain visible. Agreement does not establish correctness;
  cross-model scores are uncalibrated and are not directly comparable.
- Model setup shows availability, licenses and required actions. Explicit configured-tag
  Ollama downloads require terms acknowledgment and show actual layer-byte progress.
  Gated access and separate model services require user setup; the UI cannot unlock them.
- English/German tooltips explain controls, fields, status and metrics.
- HTML/PDF manuals and Markdown instructions use short actions, exact commands,
  checkpoints and recovery steps. Architecture/code/documentation review fixes are included.

## Included and deferred

This is a public source release with operator manuals. It contains no patient images,
rendered slices, model weights or secrets. Use the source-checkout setup; the wheel smoke
gate alone does not establish a standalone configured application installation.

Inference remains loopback-only. LAN inference, reference-scored benchmarking, acquisition
automation and the frozen holdout evaluation remain separate work. Model accuracy is
unmeasured. No automatic release or package-publication workflow is introduced.

## Validation

The release must pass the complete repository pipeline before publication. Tests use
synthetic studies and mocked model/download endpoints. See the committed plan, MVP test
record and review for the final counts and limitations.

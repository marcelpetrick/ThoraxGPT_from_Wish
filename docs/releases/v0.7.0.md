# ThoraxBench Local 0.7.0 — Clearer reviews and a 40-second preview

ThoraxBench Local is a local workbench for looking through a chest CT privately: a
lung-nodule detector checks the whole volume and the app tells you, in plain language,
where to look and what to show a radiologist. This release makes the full thorax review
read correctly without an image model, smooths the slice viewer and adds a short preview
video.

### New since 0.6.1

- **README for people, not just researchers.** The front page now starts with what the
  tool does for someone holding their own chest CT, a five-step quickstart and an honest
  model table; the detailed workflows moved to `docs/research-workflows.md`, and every
  document is indexed in `docs/README.md`.
- **Full thorax review without an image model reads right.** A detector-only review no
  longer lists all 16 findings (including the nodule it just found) as "could not be
  checked". It shows what the detector and the density rules checked over the whole
  volume, and which finding types still need an image-model sweep.
- **Honest time estimates.** The first estimate for the nodule detector is 1–3 minutes,
  not the 1–15+ minutes meant for image models.
- **Smooth scrolling.** The slice viewer keeps the current slice on screen until the next
  one has loaded, instead of flashing a loading placeholder on every slider step. Analysis
  still waits for the requested slice.
- **Wording fixes.** The density baseline's verdict no longer claims "other areas were not
  looked at" after checking the whole volume, and the German full-review disclaimer lost a
  doubled word.
- **Preview video.** `media/promo-16x9.mp4` (40 s, voice-over) shows a real detector review
  on the public LIDC-IDRI-0027 example; story and credits in
  `docs/linkedin-promo-2026-10-20.md`. The recorder is `scripts/promo_video.py`.
- **Security.** certifi 2026.10.19 fixes GHSA-6q48-6c7w-9gw2.

### Available research workflow

The workbench includes optional MONAI lung-nodule candidate review, sequential local-model
jobs, self-contained HTML reports with image evidence, English/German UI and light/dark
modes. Model weights require explicit setup; opening a folder does not start inference.
The repository's approved 30-second demo videos are in `media/`, with attribution and
selected-case/training-overlap limitations.

### Start from the repository root

```bash
uv sync --frozen --all-groups
uv run thoraxbench serve
```

Open http://127.0.0.1:8000. Optional detector setup is documented in
`docs/detector-baseline.md`; no weights are downloaded automatically.

### Scope and limitations

Research use only. This self-made experimental tool may produce incorrect, incomplete or
misleading findings. It is not professional medical advice, a diagnosis or a medical device.
Do not use outputs for diagnosis or treatment decisions.

MONAI proposals are uncalibrated; its LUNA16 training overlaps LIDC. With the parser fix, MedGemma
answered "absent" for every label in test runs, including known nodules; it is a research
control (3️⃣), not a reader. Passing software tests does not
establish model accuracy. The patient-level 20% sealed holdout remains excluded from
development and this release validation. Local registrations, the queue and downloadable job diagnostics remain session-only.
Sanitized job event logs persist across server restarts with bounded local rotation.

See `docs/model-test-runs-2026-10-20.md`, `docs/full-review.md` and
`docs/review-ui-redteam-2026-10-19.md` for evidence and review fixes, and `docs/manual.pdf` in the repository or the attached `manual.pdf` for the
operator procedure. Checksums accompany the wheel, source archive, manual and diagnostic helper.
The helper requires the installed project environment; from a checkout use
`uv run --no-sync python scripts/dcom_evaluator.py --help`.
